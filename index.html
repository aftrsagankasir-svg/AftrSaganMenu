📖 Tentang Aplikasi

Buku Menu Digital / Digital Showcase interaktif untuk Aftr Sagan. Berjalan sebagai halaman web lokal (HTML/CSS/JS) di dalam Fully Kiosk Browser, menampilkan slideshow menu dengan zoom, overlay jam tutup, dan shortcut aplikasi — semua tanpa keluar dari mode kiosk.

🧭 Cara Penggunaan

• Geser layar untuk pindah slide menu.
• Cubit (pinch) layar untuk zoom, geser 1 jari untuk memindahkan tampilan saat zoom.
• Tekan ikon ⚙️ lalu masukkan PIN untuk membuka Pengaturan.
• Di tab Aplikasi, tekan ikon untuk membuka app, tekan & tahan untuk edit/hapus shortcut.

🛠️ Info Build

Versi Aplikasi: 1.0.0
Platform: Fully Kiosk Browser (Android WebView)
Penyimpanan Data: LocalStorage (lokal per perangkat)
Sumber Gambar Menu: Google Drive
